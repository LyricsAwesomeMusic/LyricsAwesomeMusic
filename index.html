1
Go to console.firebase.google.com → Create project (free)
2
Click Firestore Database → Create → Start in test mode
3
Click Storage → Get started → Test mode
4
Project Settings → Add Web App → Copy the firebaseConfig object
5
Paste the entire config JSON below and click Connect

STEP BY STEP:
1. Click the button below to open your GitHub Releases
2. Click Create a new release
3. In Tag field type: v1.0 (or v2.0, v3.0 for new batches)
4. Scroll down → drag your images or MP3 files into Attach binaries
5. Click Publish release
6. Click on the uploaded file → Copy link address
7. Paste that link in the Music or NFT tab ✅
